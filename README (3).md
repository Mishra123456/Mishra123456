## Projects

### [TrustScope](https://github.com/Mishra123456) — Human–AI Trust Analytics
> *"What happens when users stop trusting AI? I built a system to detect that."*

```
Input  → user confidence notes + override behavior logs
Output → trust score (LOW / MEDIUM / HIGH) + weekly decay report
Stack  → Python · Scikit-learn · NLP · Logistic Regression · Pandas
```

- Extracted **sentiment polarity** + **skepticism indicators** from raw unstructured text
- Deployed Logistic Regression pipeline scoring override risk into 3 tiers
- Weekly trust trend tracking: volatility, decay rate, system health summaries

---

### [DegradX](https://github.com/Mishra123456) — Predictive Maintenance Platform
> *"Random Forest sees now. LSTM sees what's coming. Together they predict machine death."*

```
Input  → real-time multivariate sensor streams
Output → health score, failure probability, severity tier
Stack  → FastAPI · LSTM · Random Forest · Scikit-learn · Python
```

- FastAPI backend with **5+ REST endpoints** (health, reliability, severity, clustering)
- **20-cycle LSTM smoothing window** for temporal degradation modeling
- Normalized multivariate sensor data using consistent feature scaling

---

### [Emotion AI](https://github.com/Mishra123456) — Wallpaper Personalization
> *"Your wallpaper should know how you feel."*

```
Input  → user face image
Output → emotion-matched 1920x1080 wallpaper
Stack  → Vision Transformer (ViT) · FastAPI · Procedural generation · Python
```

- **ViT** for facial expression classification across **7 emotional states**
- Rule-based generator → emotion-specific color palettes + gradients
- Exposed via FastAPI image generation endpoint
